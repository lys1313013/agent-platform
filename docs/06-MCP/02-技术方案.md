## 1. API 端点清单

### 已实现

| 方法 | 路径 | 描述 | 权限 |
|------|------|------|------|
| GET | `/api/admin/mcp-servers` | 列出所有 MCP Server | 管理员 |
| POST | `/api/admin/mcp-servers` | 创建 MCP Server | 管理员 |
| GET | `/api/admin/mcp-servers/{id}` | 获取单个 MCP Server | 管理员 |
| PUT | `/api/admin/mcp-servers/{id}` | 更新 MCP Server | 管理员 |
| DELETE | `/api/admin/mcp-servers/{id}` | 删除 MCP Server | 管理员 |
| POST | `/api/admin/mcp-servers/{id}/refresh` | 刷新连接 | 管理员 |
| GET | `/api/admin/mcp-servers/{id}/tools` | 查看工具列表 | 管理员 |
| GET | `/api/tools` | 列出所有工具（含 MCP） | 登录用户 |

## 2. 数据模型

### mcp_servers 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | VARCHAR(128) | 显示名称 |
| transport_type | VARCHAR(32) | 传输类型：sse / streamable-http |
| url | VARCHAR(512) | 服务端点 URL |
| headers | JSONB | HTTP 请求头 |
| is_active | BOOLEAN | 是否启用 |
| tool_prefix | VARCHAR(32) | 工具名称前缀 |
| timeout | INTEGER | 调用超时（秒） |
| status | VARCHAR(32) | 连接状态 |
| last_error | TEXT | 最后错误信息 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |

## 3. 连接生命周期与取消

- 每个 `MCPServerConnection` 由一个专用 `asyncio.Task` 持有 transport 和 `ClientSession`，在该任务内按嵌套顺序进入、退出 SDK 上下文。SDK 内部使用 AnyIO task group，禁止在启动、HTTP 请求、重连或停机任务之间转移上下文的清理操作。
- `connect()` 等待初始化及工具发现完成；工具请求可以并发使用会话。`disconnect()` 通知持有任务退出，并等待清理完成，不直接调用 SDK 的 `__aexit__`。
- 启动被取消时终止尚未完成的初始化并回收资源；关闭期间屏蔽外层 AnyIO 取消和直接的 asyncio 取消，清理完成后继续传递调用方取消。传输任务故障只终止其连接，不取消原先创建连接的请求任务。
- 同一连接的生命周期操作互斥；并发过期调用根据失败会话身份合并重连。已删除连接禁止由旧调用重新连接。同一 Server 的管理操作也串行执行，避免并发替换遗留无人管理的连接。
- 回归见 `backend/tests/test_mcp_lifecycle.py`，包括 SSE / Streamable HTTP 的真实 SDK 调用、取消、重连、跨任务关闭，以及关闭后取消回调停止调度的检查。
