## 3. 连接生命周期与取消

- 每个 `MCPServerConnection` 由一个专用 `asyncio.Task` 持有 transport 和 `ClientSession`，在该任务内按嵌套顺序进入、退出 SDK 上下文。SDK 内部使用 AnyIO task group，禁止在启动、HTTP 请求、重连或停机任务之间转移上下文的清理操作。
- `connect()` 等待初始化及工具发现完成；工具请求可以并发使用会话。`disconnect()` 通知持有任务退出，并等待清理完成，不直接调用 SDK 的 `__aexit__`。
- 启动被取消时终止尚未完成的初始化并回收资源；关闭期间屏蔽外层 AnyIO 取消和直接的 asyncio 取消，清理完成后继续传递调用方取消。传输任务故障只终止其连接，不取消原先创建连接的请求任务。
- 同一连接的生命周期操作互斥；并发过期调用根据失败会话身份合并重连。已删除连接禁止由旧调用重新连接。同一 Server 的管理操作也串行执行，避免并发替换遗留无人管理的连接。
- 回归见 `backend/tests/test_mcp_lifecycle.py`，包括 SSE / Streamable HTTP 的真实 SDK 调用、取消、重连、跨任务关闭，以及关闭后取消回调停止调度的检查。

## 4. 工具 Schema 校验与故障隔离

- 在 OpenAI 兼容接口及 Anthropic 的 LLM 请求边界统一处理工具定义，覆盖流式、非流式调用，适用于内置、MCP 和自定义 HTTP 工具。实现位于 `backend/src/aio_agent_platform/llm/tool_schema.py`。
- 仅修改本次请求的副本：将 Schema 数值约束（如 `minimum: "1"`）转换为数值；长度、数量约束要求非负整数。递归处理 `properties`、`$defs`、组合及数组子 Schema，不转换 `default`、`enum`、`const`、示例和扩展字段中的业务值。缺失根 `type` 时补为 `object`，空 Schema 补为空对象参数定义。
- 使用 `jsonschema` 校验 Schema 自身；声明标准 `$schema` 时使用对应草案，否则使用 Draft 2020-12。无法修复的定义从本次模型请求排除，其他工具与对话继续，不回写数据库和 MCP 缓存。
- 服务端仍返回明确的 `Invalid schema for function/tool '<工具名>'` 400 时，仅剔除请求中匹配的工具并重发；每次剔除一个工具，最多恢复本次请求的工具数量次。全部剔除后不携带工具。流式恢复仅限获取流之前；Anthropic 在进入流上下文时处理。输出开始后不重放，无明确工具名的错误和其他请求错误按原流程传播。
- 兼容转换记录 WARNING `llm_tool_schema_normalized`（工具名、模型、提供商、字段路径）；本地校验失败记录 ERROR `llm_tool_schema_invalid`；服务端拒绝后剔除重试记录 ERROR `llm_tool_schema_rejected`。日志仅保留定位元数据，不输出完整 Schema、描述、参数默认值或服务端原始错误正文。
- 回归见 `backend/tests/test_tool_schema.py`，覆盖数值字符串、嵌套 Schema、非法定义隔离、原始定义不变、日志内容、两类提供商四种调用入口，以及剔除重试边界。
