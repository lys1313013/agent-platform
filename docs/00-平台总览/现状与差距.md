## 1. 差距与优先级

按"不补就无法向企业交付"排序，而不是按实现难度：

### P0 — 企业版上线前必须完成

1. **审计日志接线**：审计表已存在但无写入。至少要覆盖登录、权限变更、资源增删改、智能体发布、工具执行、数据导出。
2. **RBAC 与资源级权限**：租户内角色（管理员/成员/只读）、智能体/知识库/工具的授权、部门维度。
3. **服务账号与 API Key**：对外 API 不能依赖人类 JWT；需要 Key 管理、轮换、限流、审计。
4. **配额与限流执行**：至少租户级 token/费用/并发上限，超限有明确行为。
5. **提示词注入与敏感信息防护**：输入过滤、工具返回内容标记、危险动作确认、日志脱敏。
6. **备份恢复与数据删除**：数据库 + 对象存储备份、租户级导出与删除。
7. **SSO**：OIDC/SAML 至少支持一种；企业采购的硬门槛。
8. **任务级运行模式**：Ask / Plan / Agent 三档 + Agent 全自动档、计划批准、模式切换与审计。需求见 [运行模式](../能力域/D02-智能体运行时/运行模式/01-需求.md)。

### P1 — 生产运营必需

9. 智能体发布流程：草稿/发布、差异、灰度、回滚、审批。
10. 评测体系：回归集、离线评分、线上质量指标、badcase 回流。
11. 告警与 SLO：错误率、延迟、成本、沙箱、渠道。
12. 统一工具策略：出站白名单、凭证 KMS、工具版本、调用熔断。
13. 多实例与队列：长任务跨实例、死信、幂等。
14. 渠道与集成扩展：钉钉/Slack/Teams、Webhook 事件、嵌入组件。
15. 私有化交付：Helm、离线包、备份脚本、升级回滚手册。

### P2 — 竞争力与生态

16. 智能体/技能/工具市场与模板。
17. A2A 协议与跨平台互操作。
18. SDK、开发者门户、沙盒环境。
19. 成本分摊账单与成本中心。
20. 多语言、无障碍、移动端。

## 2. 企业版验收清单

### 身份与权限
- [ ] 支持企业 SSO（OIDC/SAML），可映射到租户与角色
- [ ] 支持 MFA 或可对接企业 MFA
- [ ] 租户内至少有管理员/成员/只读三种角色
- [ ] 智能体、知识库、工具可授权到部门或成员
- [ ] 离职/停用后会话与凭证立即失效
- [ ] 服务账号与 API Key 可创建、轮换、吊销

### 数据隔离
- [ ] 跨租户数据访问在数据库与应用层双重阻断
- [ ] 知识库检索结果按调用者权限过滤
- [ ] 记忆与画像不跨用户、不跨租户
- [ ] 对象存储产物按租户隔离且可审计

### 智能体运行
- [ ] 单次任务有最大步数、超时、预算
- [ ] 支持中断、后台运行、断线重连
- [ ] 模型故障可降级到备用模型
- [ ] 子智能体权限不超过父级，预算可传播

### 安全与合规
- [ ] 高风险工具默认需人工确认，确认参数可见
- [ ] 沙箱网络默认关闭，可按需白名单
- [ ] 工具凭证不出现在提示词、日志、产物中
- [ ] 提示词注入有多层防护
- [ ] 审计日志覆盖关键操作，可检索、可导出
- [ ] 支持数据留存策略、导出、删除
- [ ] 有安全事件响应流程与联系人

### 可观测与成本
- [ ] 每次调用可还原完整轨迹
- [ ] 有 token/费用按租户、用户、智能体、模型的分组统计
- [ ] 成本/错误/延迟可配置告警
- [ ] 有 SLO 与错误预算

### 交付与运维
- [ ] 支持私有化部署，依赖清晰
- [ ] 提供备份与恢复方案，定义 RPO/RTO
- [ ] 提供升级与回滚流程
- [ ] 提供健康检查与监控接入方式
- [ ] 提供容量规划与扩容说明

### 质量与运营
- [ ] 智能体有版本、发布、回滚
- [ ] 有离线评测集与回归测试
- [ ] 有线上质量指标与用户反馈闭环
- [ ] 有智能体下线与依赖检查流程
