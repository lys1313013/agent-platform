# 用户画像安全编辑 — 需求

> 让智能体按用户意图精确修改画像，而不是整份覆盖：变更可控、冲突可发现、历史可追溯。技术实现见 [设计](02-设计.md)。

## 1. 背景与问题

用户画像描述角色、偏好、沟通风格和长期目标，每轮对话注入系统提示，是个性化的主要输入。当前的问题集中在“怎么改”而非“有没有”：

- 画像以整份 Markdown 保存。智能体要改一处细节，只能读取全文再整份写回，遗漏的任何内容都会被静默删除。
- 多个会话或设置页面同时编辑时，后写者直接覆盖先写者，双方都看不到冲突。
- 覆盖式写入无法回答“谁在什么时候把哪条偏好改成了什么”，出问题后难以定位和回退。
- AI 自动修改与用户人工编辑缺少清晰边界，用户难以判断画像中哪些内容由模型改动。

## 2. 目标

- 支持以“首次创建、追加、精确局部替换、清空、全文重写”五类意图表达变更，模型无需整份重写。
- 变更建立在对当前内容的预期之上：内容已被他人改动时写入失败，而不是覆盖。
- 每次成功修改保留修改前版本，并区分来源，支持事后追溯。
- 明确 AI 修改与人工编辑的边界，AI 不得借全文重写绕过冲突。
- 画像修改后，当前对话立即使用最新画像。

## 3. 范围

### 3.1 纳入

- 当前执行租户下当前用户画像的读取。
- 画像的首次创建、追加、唯一匹配替换（含局部删除）、清空、全文重写。
- 并发冲突检测与拒绝。
- 修改前快照、来源标记、内容未变化不产生快照。
- 画像被修改或读取后，当前对话上下文的刷新。
- 参数合法性校验先于任何持久化。

### 3.2 不纳入

- 设置页面的人工编辑交互改造（继续沿用现有全文保存方式）。
- 画像内容的自动提取、自动推断或自动补全策略。
- 画像历史版本的查看、对比与恢复界面。
- 跨租户共享画像或画像的租户级策略配置。
- 画像导出、保留期与彻底遗忘（属记忆域其他事项）。

## 4. 功能需求

### 4.1 读取与操作类型

- 读取：返回当前执行租户中当前用户的完整画像，没有画像时返回空；不返回他人或其他租户的内容。
- 首次创建：仅在画像为空时成功；已有非空画像时拒绝。
- 追加：只追加新增内容，不改动已有内容；画像为空时要求先创建。
- 替换：以给定原文精确且唯一匹配后替换；新内容可为空，用于删除局部片段。
- 清空与全文重写：要求提供预期全文，与当前画像一致才执行。
- 每次调用必须显式指定操作，且只接受该操作对应的字段。

### 4.3 匹配与冲突

- 原文找不到、匹配到多处（包括重叠匹配）时拒绝操作。
- 拒绝时提示重新读取最新画像、补充定位上下文后再编辑，不得自动降级为全文重写绕过匹配失败。
- 只有用户明确要求清空或全文重写时才使用对应操作。

### 4.4 输入校验

- 空正文、缺少必需字段、字段类型错误、与操作无关的多余字段、NUL 字符，一律在访问存储之前拒绝。
- 局部替换不得隐式清空整份画像。
- 旧式只提交全文、不声明操作的调用不再接受。

### 4.5 版本与来源

- 每次成功修改前的非空画像保存为历史快照，来源标记为智能体生成。
- 快照与画像修改在同一事务中提交；内容没有实际变化时不新增历史快照。

### 4.6 权限与隔离

- 每次调用要求已绑定的执行租户上下文，并重新校验用户启用状态、租户启用状态与实际成员资格。
- 画像按用户与租户隔离；运行中切换界面租户不改变画像归属，也不改写用户所属租户。
- 通过工具白名单限制能力时，读取与更新需同时开放，缺一即不可用。

### 4.7 当前对话生效

- 一批工具执行完成后，若画像被读取或修改，重新从存储读取最新画像并刷新后续模型请求的系统提示。
- 并行工具结果的返回顺序不代表提交顺序，不得按返回顺序覆盖画像上下文。
- 刷新失败时记录并保留原上下文，不中断对话。

## 5. 非功能需求

### 5.1 一致性

- 更新以读取时的原文作为写入条件；读取后其他会话或设置页面已修改画像时，本次更新失败并要求重新读取。
- 并发首次创建依靠用户与租户的唯一性检测冲突，只允许一个成功。

### 5.2 安全

- 用户、租户身份来自可信执行上下文，模型不能指定他人身份或租户。
- 权限或成员资格被撤销后，下一次调用即失败，不因既有会话而放行。

### 5.3 可追溯与可用性

- 每次成功变更可回答：改了什么、改前是什么、来源是 AI 还是人工。
- 冲突失败不产生历史快照，不留下半成品记录。
- 歧义或冲突必须给出可操作的提示（重新读取、补充定位上下文），而不是笼统失败。

## 6. 验收标准

- [ ] 空画像首次创建成功；对已有非空画像再次创建被拒绝
- [ ] 追加只追加新内容，已有文本逐字保留；空画像追加时被要求先创建
- [ ] 替换在原文唯一匹配时成功，替代内容正确
- [ ] 原文不存在或多处匹配时拒绝，且画像与版本记录均未改变
- [ ] 替换的新内容为空时仅删除匹配片段，画像其余内容完整保留
- [ ] 清空与全文重写在预期全文一致时成功，不一致时拒绝
- [ ] 缺少字段、类型错误、无关字段、NUL 字符、空正文均在写入前被拒绝
- [ ] 旧式仅提交全文的调用被拒绝，且未产生写入
- [ ] 两个基于同一原文的并发修改只有一个成功，另一个收到冲突
- [ ] 并发首次创建只有一个成功，另一个收到冲突
- [ ] 每次成功修改生成一条修改前快照并标记为智能体生成；内容无变化时不生成快照
- [ ] 冲突失败的写入不生成历史快照
- [ ] 切换界面租户不影响画像归属，也不改写用户所属租户
- [ ] 用户或租户被停用、成员资格被撤销后，下一次调用失败
- [ ] 工具白名单只开放读取或只开放更新时，能力按配置生效，不存在隐式放行
- [ ] 画像修改后，当前对话后续的模型请求使用最新画像
- [ ] 并行工具返回顺序不影响画像上下文，以存储中的最新内容为准
- [ ] 刷新画像失败时对话继续，使用原有上下文且不报错中断
