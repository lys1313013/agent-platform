### 智能体卡片

#### 卡片内容

| 区域 | 内容 | 说明 |
|------|------|------|
| 图标 | emoji 表情 | 大字号居中展示 |
| 名称 | 智能体名称 | 粗体 |
| 描述 | 一行描述 | 最多 2 行，超出截断 |
| 标签 | 模型名 / 工具数 / 技能数 | 底部标签行，紧凑排列 |

#### 卡片交互

- **点击卡片** → 直接进入该智能体的对话页面 (`/agents/:id/chat`)
- **hover 效果** → 轻微上浮 + 阴影加深
- **所有者 / 管理员额外元素**：
  - 右上角显示状态标签（启用/禁用）
  - 右下角 `···` 菜单：编辑、删除

#### 空状态

无智能体时显示空状态插图 + 提示文案：
- 管理员："还没有智能体，点击上方按钮创建第一个"
- 普通用户："还没有智能体，点击上方按钮创建你的第一个智能体"

### 创建智能体

#### 权限

所有用户均可创建智能体，创建后拥有完整配置权限。

| | 普通用户 | 管理员 |
|---|---------|--------|
| 创建 | ✓ | ✓ |
| 配置（提示词、模型、工具、技能、子智能体） | ✓（自己创建的） | ✓（所有） |
| 删除 | 只能删除自己创建的 | 可删除所有 |

#### 创建表单（弹窗）

| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| 名称 | Input | ✓ | 如：编程助手、文档专家 |
| 图标 | Select（emoji 选择器） | ✓ | 10 个预设 emoji |
| 描述 | Input | | 一句话描述 |
| 系统提示词 | TextArea + 模板选择 | | 留空使用默认 |
| 欢迎语 | TextArea | | 新会话开场白 |
| 模型 | Select | | 选择 LLM 模型，留空使用全局默认 |
| 温度 | InputNumber (0~2) | | 推理温度，留空则不传该参数（使用模型服务商默认） |
| 工具 | Checkbox.Group | | 勾选启用的工具 |
| 技能 | 多选 Select | | 搜索并绑定技能 |
| 子智能体 | 多选 Select | | 关联子智能体用于任务委派 |
| 启用状态 | Switch | | 创建后是否立即可用 |

#### 创建成功后

- 弹窗关闭
- 新卡片出现在列表中
- 自动跳转到该智能体的对话页面

## 智能体左侧菜单

> 智能体对话页面左侧侧边栏的菜单结构与功能需求。

---

### 布局

左侧默认显示图标导轨（窄条），点击图标展开对应面板，同一时间只展开一个，点击外部或关闭按钮收起。

菜单分三组，组间用分隔线隔开：

| 分组 | 菜单项 |
|------|--------|
| 概览 | 概览 |
| 管理 | 大模型配置、系统提示词、技能 & 工具、子智能体 |
| 用户 | 记忆、会话历史 |

导轨底部固定两个快捷按钮：**＋ 新对话**、**🔄 刷新**。

---

### 概览

展示智能体的运行摘要和基本信息。

- **统计卡片**：调用次数、平均耗时、最后运行时间
- **基本信息**：名称、使用的模型、描述、状态
- **关联摘要**：子智能体数量、绑定技能数量、启用工具数量（可点击跳转到对应面板）

---

### 大模型配置

- **大模型**：下拉选择，列出所有可用模型，标记默认模型，留空则使用全局默认
- **温度**：数值输入（0~2），留空则不传 temperature 参数（使用模型服务商默认值），支持一键重置

---

### 系统提示词

- **模板选择器**：从预设模板加载提示词
- **系统提示词**：多行文本编辑，留空使用默认
- **欢迎语**：新会话开始时展示的消息，留空使用默认

---

### 技能 & 工具

分两个区域，在同一个面板内展示：

**技能区域**：
- 多选搜索框，添加技能
- 已绑定技能以卡片列表展示（名称、描述、分类标签），支持单个移除或全部移除

**工具区域**：
- 复选框列表，支持全选/清空
- 标记危险工具和多智能体工具
- 显示已选数量

---

### 子智能体

管理当前智能体的子级智能体（层级关系）。

- **添加**：从已有智能体中选择，或创建新的子智能体
  - 排除自身（不能自引用）
  - 排除已形成循环的智能体
  - 不超过最大深度限制（默认 3 层）
- **列表**：卡片展示每个子智能体 — 名称、描述、模型（自有或继承）、工具数
- **移除**：解除父子关系，不删除子智能体本身，需确认

---

### 记忆

查看和管理该智能体产生的用户级记忆。

- 按层级分 Tab：**L1 常驻上下文** / **L2 长期记忆** / **L3 情景记忆**
- 支持搜索、查看、编辑、删除
- L1 支持手动添加新记忆

---

### 会话历史

管理当前智能体的对话列表。

- **搜索**：按标题关键词搜索
- **分组展示**：已置顶 → 今天 → 昨天 → 更早 → 已归档
- **操作**：重命名（行内编辑）、置顶/取消置顶、归档/取消归档、删除（需确认）
- **交互**：点击切换会话，选中项高亮
