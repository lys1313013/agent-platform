# 文档与图片工具 — 需求

> 让智能体在不把整份文件塞进上下文的前提下，按范围读取、检索、渲染并查看用户上传的文档与图片，并让每个结论都能指回原文位置。技术实现见 [设计](02-设计.md)。

## 1. 背景与问题

用户在会话中上传的往往是 PDF、Word、Excel、PPT 和图片，而不是纯文本；文档解析依赖又体积较大，既不适合放在 API 宿主进程里跑，也不现实在每次对话中临时安装。让模型直接读整份文件有三个问题：

- 上下文窗口有限，长文档会被截断，模型容易把局部当全文。
- 不同格式的结构差异大：PDF 有页码，表格有单元格，幻灯片有页序，扫描件没有文本层。
- 模型是否具备视觉能力并不确定，不能让它"假装看过"图片。

平台需要一个受控、可降级、结论可溯源的文档访问层。

## 2. 目标

- 提供四类能力：范围化文档读取、文档内检索、PDF 页面渲染、图片查看。
- 所有结果携带来源位置与覆盖范围，并给出继续读取的游标；不能把局部结果当成全文。
- 扫描件与图片文字识别有明确模式、语言与布局选项，识别失败或不确定要显式告知。
- 图片查看只对具备视觉能力的模型开放；非视觉模型得到明确失败，但文字识别仍可继续使用。
- 解析在沙箱内完成，路径限定在当前工作区，默认依赖预装，不在对话中安装。

## 3. 范围

**纳入**：

- PDF（含扫描件）、DOCX、XLSX、PPTX 与常见图片的读取和 OCR。
- 范围选择：页码、章节、工作表、单元格区域、幻灯片范围。
- 在指定范围内做不区分大小写的字面检索，返回片段与位置。
- PDF 页面渲染为工作区图片，并作为文件产物展示。
- 图片查看：格式、元数据、缩放、方向、透明背景与首帧处理。
- 可选的 Office 版式渲染、Word 按页读取与旧格式转换；未启用时返回明确错误。
- 分页游标、覆盖范围、资源上限与失败降级，以及与既有会话上传、工作区同步和文件预览链路的衔接。

**不纳入**：

- 编辑、生成或转换文档，表格公式计算，图表数据提取。
- 旧版 DOC/XLS/PPT 的原生解析（只能走可选转换，未启用时明确拒绝）。
- 从 Office 内嵌图片、图表中直接抽取文字（需要时渲染或另行上传图片/PDF）。
- 全文索引、知识库入库与检索（属于知识库能力）。
- 跨工作区文件访问，以及无视觉能力模型的图片理解。

## 4. 功能需求

### 4.1 范围化文档读取

- 输入为当前工作区的相对路径；也接受指向当前工作区的完整路径；拒绝其他工作区和越界路径。
- PDF 按原始页码定位，返回表格时保留行列与坐标；扫描件返回 OCR 文本，不保证恢复表格单元格。
- DOCX 保留正文顺序，返回章节路径、段落号与表格单元格位置；章节按标题精确匹配并包含子章节；原生读取不覆盖页眉、页脚、文本框等版式内容，需要时提示通过渲染检查。
- XLSX 保留工作表、单元格坐标与公式表达式，但不计算公式；默认只读首个工作表的前 200 行、前 50 列，并明确返回实际覆盖范围。
- PPTX 以幻灯片号定位，返回形状与段落位置；原生读取不识别嵌入图片和图表中的文字。
- 每次返回带来源位置的文本或表格单元格块、覆盖范围与翻页游标；继续读取时必须保持路径、页码、章节、工作表等选择条件不变。
- 长文档分批读取；单次返回块数与字符总量有预算，长段落自动分块，允许继续分页。

### 4.2 文档内检索

- 在文档的指定范围内做不区分大小写的字面检索，返回原文片段与页码、章节、段落、单元格或幻灯片位置。
- 检索只对已返回的覆盖范围负责；某个页码范围或工作表无匹配，不得表述为全文无匹配。
- 每个匹配返回一段上下文，支持按偏移继续获取后续匹配。

### 4.3 PDF 页面渲染

- 按页码范围将 PDF 页面渲染为工作区图片，返回图片路径、页码与尺寸，作为文件产物展示，并进入既有工作区文件同步与预览链路。
- 默认一次渲染 1 页，单次最多 5 页；预览分辨率有下限与上限，默认取中间值。
- 渲染本身不要求模型具备视觉能力，用于版式检查后再交给图片查看。

### 4.4 图片查看

- 支持 PNG、JPEG、WebP、GIF、BMP、TIFF；图片元数据进入工具结果，实际图像通过临时多模态消息发送给视觉模型。
- 只有当前会话模型开启视觉能力时才允许查看；非视觉模型得到明确失败，不得假装已经看过图片，文字识别仍可用文档读取。
- 查看时最长边缩至 2048 像素；按方向信息矫正；透明背景以白色合成；动画与多帧图片只查看第一帧；超过 2500 万像素的图片拒绝处理。
- 图像数据不得出现在工具文本、流式事件和会话记录中，观测侧按既有图像脱敏规则处理。

### 4.5 OCR 与扫描件

- 自动模式：仅对没有文本层的 PDF 页面启用 OCR。
- 图文混排中已有文本、但仍需识别图片文字时，使用强制 OCR 模式。
- 关闭模式：完全不做 OCR；直接读取图片文字必须启用 OCR。
- 语言至少支持中文加英文（默认）、纯中文、纯英文三种组合。
- 布局至少支持自动、单文本块、稀疏文字三种模式；简单扫描页漏字时可切换单文本块。
- OCR 结果带警告，不承诺零误识别；扫描件不保证恢复表格结构。

### 4.6 格式兼容与失败降级

- Office 版式渲染、按页读取与旧格式转换属于可选能力；未启用时返回明确错误，提示改用原生格式读取或上传 PDF，不得生成冒充原始版式的简化截图。
- 损坏文件、超限文件、不支持的格式、越界路径与符号链接必须返回可解释错误，不能用空结果冒充成功。
- 解析在沙箱内执行，不在 API 宿主运行；依赖默认预装，不在对话中安装。
- 输入大小、压缩包解包总大小、页数、单元格数量、返回块数与字符数、图片像素均有上限。
- OCR、Office 子进程与整体处理都有单次与总时间预算，超时必须失败返回而不是无限等待。

### 4.7 与上传和工作区的衔接

- 用户仍通过会话上传文件，智能体使用上传后的工作区相对路径；工具沿用现有智能体工具白名单、当前工作区、沙箱执行与文件产物展示机制。
- 上传写入对象存储后，若用户有运行中的沙箱则分块写入正确工作区；没有运行中的沙箱时不为此新建容器，下次初始化再载入。

## 5. 非功能需求

| 维度 | 要求 |
|---|---|
| 安全隔离 | 解析器不在 API 宿主进程运行；只允许当前工作区内路径，拒绝越界与符号链接；渲染只写入工作区内随机子目录 |
| 数据边界 | 图片编码数据不进入工具文本、流式事件、会话记录与观测后端；只暂存于非展示字段，并在工具回复后立即清空；安全续跑时重新读取图像，不复用仅含元数据的历史缓存 |
| 权限 | 沿用工具白名单与工具级权限；智能体未勾选新增工具时不可调用 |
| 性能与成本 | 单次返回块数与字符数受预算约束，长文档必须分批读取；单次调用有整体时间预算，OCR 与 Office 子进程各有独立上限；超时返回明确错误 |
| 兼容与升级 | 默认镜像不含版式渲染组件，可选镜像才具备；运行中的旧容器不会自动获得新能力，切换前必须先同步文件，不得直接删除仍有未同步文件的容器 |
| 可用性 | 失败必须可见、可解释；不支持或未启用能力时给出替代路径，不静默降级 |

## 6. 验收标准

- [ ] 读取文本 PDF 返回页码、文本块与翻页游标，可继续读取后续页面。
- [ ] 扫描 PDF 在自动 OCR 下返回识别文本并带警告，关闭 OCR 后无文本页面明确告知无文本；中文扫描件可识别，中文加英文的默认语言组合可用。
- [ ] DOCX 按章节读取包含子章节，并返回段落号和表格单元格位置；章节不存在时返回明确错误。
- [ ] XLSX 保留公式文本但不计算，默认只读首个工作表前 200 行、50 列并返回覆盖范围，选择其他工作表或区域可继续读取。
- [ ] PPTX 按幻灯片返回形状与段落位置，不声称已识别嵌入图片或图表文字。
- [ ] 文档检索不区分大小写，返回上下文片段与位置，且只对覆盖范围下结论。
- [ ] PDF 渲染输出工作区 PNG 并出现在文件产物中，页码与尺寸正确，超过单次页数上限被拒绝；渲染结果可继续交给图片查看，渲染步骤本身不要求视觉模型。
- [ ] 支持格式的图片可查看，方向矫正、透明背景、首帧处理符合约定；非视觉模型明确失败，文字识别仍可用。
- [ ] 未启用可选 Office 能力时，版式渲染、按页读取、旧格式转换均返回明确错误并给出替代路径，不生成伪版式截图。
- [ ] 越界路径、符号链接、超限文件、损坏文件与不支持格式均被拒绝，错误可读。
- [ ] 工具文本、流式事件与会话记录中不出现图片编码数据。
- [ ] 智能体未勾选工具时不可调用；用户有运行容器时上传文件被写入正确工作区，无运行容器时不触发新建、下次初始化可读取。
