# D05 知识与检索

> **解决什么问题**：让智能体在回答前拿到"对的资料"，并且只拿到调用者有权看的那部分；回答能指回原文，而不是凭空生成。
> **适用读者**：后端、前端、知识库管理员、安全评审、交付实施。
> **关联文档**：[D01 身份组织与权限](../D01-身份组织与权限/README.md) · [D06 记忆与个性化](../D06-记忆与个性化/README.md) · [D10 安全合规与审计](../D10-安全合规与审计/README.md) · [能力全景 §5 D5](../../00-平台总览/README.md)
> **状态基准**：2026-11 代码。状态只用 `已具备 / 部分 / 缺失`；PRD 中的设计未实现的一律不计入已具备。

---

## 1. 边界

**本文负责**：
- 外部知识库接入（RAGFlow 数据集）与自建图谱知识库。
- 文档上传、解析、切分、实体关系抽取。
- 检索入口：知识库检索、图谱检索、文档读取/检索工具、大文件访问工具。
- 检索结果的权限过滤、来源信息与上下文注入。
- 知识库资源管理与 Agent 绑定。

**本文不负责**：
- 网页搜索与网页抓取 → D04 工具与外部集成。
- 工作区文件存储、沙箱生命周期与产物链路 → D04。
- 会话上下文压缩、会话摘要 → D02 智能体运行时。
- 用户记忆、画像与技能 → D06。
- 知识库操作的审计留痕与配额 → D10 / D12。

**设计底线**：检索必须同时满足三件事——**查得准**（召回相关片段）、**权限对**（在数据查询条件里过滤，不是先查后删）、**可溯源**（能回到文档/页码/分块）。缺任何一项，知识库在企业环境里都不可用。

## 2. 能力清单

### 2.1 知识接入

| 接入方式 | 企业要求 | 关键点 |
|---|---|---|
| 文件上传 | 必须 | PDF/Office/图片/表格；大小与类型校验；工作区配额 |
| 网页抓取 | 常见 | 与知识库入库解耦，抓取结果可再入库 |
| 数据库同步 | 中大型企业 | 增量游标、字段映射、权限继承 |
| API 同步 | 常见 | 幂等、失败重试、删除传播 |
| 增量更新 | 必须 | 文档变更后索引可更新；删除可下架 |

### 2.2 解析

| 能力 | 说明 |
|---|---|
| 版面分析 | 标题层级、段落、列表、表格结构 |
| 表格抽取 | 保留单元格坐标；不把表格拍平成不可读文本 |
| OCR | 扫描 PDF、图片；中英文；失败要显式报错 |
| 公式/图表 | 可选；不支持时明确说明，不假装已解析 |

### 2.3 切分与索引

- 切分：固定长度、按结构（Markdown 标题/章节）、语义切分；必须有重叠与来源定位。
- 索引：向量、关键词（BM25/全文）、混合检索；元数据过滤（租户/知识库/文档/标签）。
- 重排：重排或融合排序；多知识库结果去重与稳定排序。
- 查询侧：查询改写、同义词扩展、实体链接。

### 2.4 检索

| 能力 | 最低要求 |
|---|---|
| 召回 | Top-K + 分数阈值；空结果明确返回 |
| 多库融合 | 并发查询、按分数合并、限制总量 |
| 上下文预算 | 单片段截断、总长度受控 |
| 降级 | 外部检索失败不影响对话主流程 |
| 评测 | 固定问题集、召回率/准确率、回归基线 |

### 2.5 权限

- 知识库级：租户 + 可见范围（租户内可见/仅创建者可见）+ 启用状态。
- 文档级：某文档只对指定用户/部门可见；段落级：敏感片段过滤（企业合规场景）。
- **硬性要求**：权限条件必须进入检索的数据查询；不能先检索再按权限删除结果，否则会泄露"存在性/数量"。

### 2.6 溯源与治理

- 引用：文档标题、页码/章节/段落、分块标识、原始链接。
- 生命周期：文档版本、更新、下架、删除传播；可信度：来源标记、人工复核状态、抽取置信度。
- 评测与运营：检索日志、命中率、无结果率、点击回流。

### 2.7 知识图谱

- 抽取：实体/关系三元组，带类型、描述、置信度、来源分块；同名实体归一化合并，同源同目标同类型关系去重。
- 复核：待确认/已采纳状态；未采纳数据不进入检索。
- 检索：实体链接 + 多跳子图遍历，结果可回到来源分块。
- 融合：与向量/关键词检索结果统一排序（长期目标）。

## 3. 本项目现状

### 3.1 已具备

| 能力 | 实现 |
|---|---|
| RAGFlow 接入与配置 | 调用外部知识库检索接口；按数据集并发查询，单库失败不拖垮整体；地址与密钥存平台配置，管理接口读写且密钥不回显 |
| 知识库管理 | 增删改查、启用/禁用、连接测试、检索测试；按租户与可见范围过滤 |
| Agent 绑定 | 智能体与知识库多对多绑定；创建/更新智能体时校验租户与可见范围 |
| 检索注入与执行 | 绑定后自动注入知识库检索工具；执行时校验租户、绑定、启用、可见范围；返回条数上限 20，片段截断 1500 字符 |
| 图谱知识库 | 增删改查、文档粘贴/上传、分块、异步模型抽取、实体/关系人工采纳、检索测试 |
| 图谱检索 | 中文分词 + 文本相似度实体链接，递归图遍历扩展（默认 2 跳，最多 5 跳，最多 200 条边） |
| 图谱可视化 | 管理端图谱页与详情页；后端提供实体/关系/分块查询 |
| 文档工具 | 文档读取、文档检索、页面渲染、图片查看；返回页码/章节/段落/单元格位置与分页游标 |
| 大文件工具 | 文件信息、正则搜索、只读结构化查询、PDF 读取；直接读取文件有 1 MB 守卫与字符分页 |
| 文件上传 | 会话上传接口：单文件与工作区各 500 MB、文件类型魔数检测、写入对象存储并注入活动沙箱 |
| 工具结果文件 | 超过 5 万字符时保存到工作区文件，返回预览与读取入口 |

### 3.2 部分

| 能力 | 现状 | 缺口 |
|---|---|---|
| 统一检索抽象 | 知识库检索、图谱检索、文档工具各自实现 | 没有统一检索后端接口；新增检索源需要改工具与处理器 |
| 检索质量 | 依赖 RAGFlow 外部召回；图谱按实体名相似度召回 | 无自研混合检索、重排、查询改写；无评测集与指标 |
| 切分可控性 | 图谱自建切分；RAGFlow 切分在外部系统 | 平台无法统一控制 RAGFlow 的分块策略与索引参数 |
| 权限粒度 | 知识库级租户 + 可见范围；图谱文档继承知识库 | 无文档级/段落级权限；检索前过滤只到知识库级 |
| 溯源 | 图谱实体/关系保存来源分块；文档工具返回位置 | 图谱检索输出未带来源分块；RAGFlow 引用展示不完整；无统一引用契约 |
| 图谱抽取 | 异步任务、状态机、失败重试、同名实体合并 | 每次对全库分块重跑，不能按文档选择；上传后不自动触发；无增量抽取 |
| 扫描件 | 图谱上传支持 MinerU OCR 路径，需 MinerU 配置 | 未配置时明确报错 |
| 大文件分析 | 文件信息有进程内分析缓存；正则搜索与结构化查询可用 | 无文件摘要/切片；缓存不持久化；上传后不自动入库 |
| 文档治理 | 图谱文档可删除、删除后不参与抽取/检索 | RAGFlow 数据集无文档生命周期管理；无版本、失效下架、增量同步 |

### 3.3 缺失

- 文档级/段落级权限过滤。
- 混合检索与重排；可替换的检索后端抽象。
- 检索质量评测（黄金集、召回率/准确率、回归门禁）。
- RAGFlow 文档增量同步、删除传播、索引版本管理。
- 统一引用契约与前端可点击溯源；跨知识库结果去重与稳定融合排序。
- 知识来源可信度与内容审核流程。

## 4. 关键设计

### 4.1 知识模型与归属

**RAGFlow 知识库**

- 记录名称、数据集标识、描述、启用状态、创建者与可见范围。
- 智能体与知识库为多对多绑定；删除知识库时解除绑定。

**图谱知识库**

- 具备同样的租户、创建者与可见范围归属；当前使用租户默认模型，未单独配置抽取模型。
- 文档与分块：保存原文、来源类型、顺序、内容与分块数量。
- 实体：名称、归一化名称、类型、描述、扩展属性、来源分块、审核状态；同一知识库内归一化名称唯一。
- 关系：来源实体、目标实体、关系类型、置信度、来源分块、审核状态。
- 抽取任务：状态、总块数、已处理块数、实体数、关系数、错误信息。
- 智能体与图谱知识库存在独立绑定关系。

### 4.2 RAGFlow 检索流程

1. Agent 绑定知识库后，自动注入知识库检索工具。
2. 处理器从执行上下文取智能体标识，并解析执行租户。
3. 查询绑定且启用的知识库，条件包含租户、租户内可见或当前用户创建。
4. 读取平台配置中的 RAGFlow 地址与密钥；缺失时返回明确错误。
5. 对每个数据集并发调用检索接口，单库异常被忽略。
6. 合并记录、按分数降序、截取上限；失败或空结果返回可读文本，由 Agent 决定继续回答或告知用户。

### 4.3 图谱构建与检索流程

**构建**：
1. 文档粘贴或上传；Markdown/文本/HTML/PDF/Word 直接解析，扫描 PDF 走 OCR 任务。
2. 按 Markdown 标题分段，每段按 800 字符切分、80 字符重叠。
3. 管理员触发抽取任务；同一知识库同时只允许一个待执行/执行中任务，逐分块调用默认模型并要求结构化实体/关系，非法输出计入失败分块。
4. 实体按归一化名称去重；关系按来源、目标、类型去重；新数据默认待确认。
5. 管理员采纳后状态变为已采纳；全部失败时任务标记失败，可重试。

**检索**：
1. 查询绑定、启用、可见的图谱知识库。
2. 对查询分词，用文本相似度与子串匹配取前 5 个实体作为种子。
3. 从种子出发递归扩展，默认 2 跳、最多 5 跳、最多 200 条边；只取已采纳，序列化为实体清单与三元组清单返回 Agent。

### 4.4 文档与大文件访问

- 文档解析在沙箱 worker 中执行；路径必须位于当前工作区，拒绝越界与符号链接。
- 返回覆盖范围、下一页、下一偏移，要求模型分批读取，不能把局部当全文。
- 直接读取文件对超过 1 MB 的文件要求分页参数；超长工具结果转为工作区文件。
- 结构化查询只允许只读查询，禁止写入、删除与结构变更。

### 4.5 失败模式

| 场景 | 后果 | 当前处理 |
|---|---|---|
| RAGFlow 不可达 | 检索工具报错 | 返回错误文本，对话继续；无自动切换其他后端 |
| 单个数据集失败 | 少召回 | 忽略异常，其余结果照常合并 |
| 知识库被禁用/删除 | 不再召回 | 查询条件过滤；删除时解除绑定 |
| 图谱抽取全部失败 | 无新实体 | 任务失败并记录原因，可重试 |
| 部分分块失败 | 图谱不完整 | 任务仍完成，失败数只写日志，未在任务上展示 |
| 未采纳实体 | 不参与检索 | 检索只取已采纳 |
| 文档路径越界/符号链接 | 安全风险 | worker 拒绝 |
| 大文件直接读 | 上下文爆炸 | 1 MB 守卫 + 分页 + 工具结果文件 |

## 5. 实施建议

### P0（交付阻断）

1. **统一检索契约**：定义可替换的检索后端接口（查询、范围、条数 → 结果）；RAGFlow、图谱、文档检索都实现它；工具层只依赖接口。
2. **统一引用结构**：每条结果必须包含来源类型、资源标识、文档标题、位置（页码/章节/分块）、片段标识；前端提供可点击溯源。
3. **知识库级权限收口**：把租户、可见范围、启用状态、创建者的过滤抽成统一函数，禁止各处理器各写一份。
4. **上传即可检索**：工作区上传文档后提供显式"加入知识库"动作，落到 RAGFlow 或图谱，不让用户手工复制数据集标识。

### P1
5. **检索质量基线**：建立 30–50 条固定问答集，记录召回率、无结果率、引用正确率；每次改检索逻辑跑回归。
6. **图谱增量抽取**：按文档选择抽取、仅处理新增/变更分块；抽取失败分块在任务详情可见。
7. **混合检索**：关键词 + 向量 + 图谱结果融合排序；先做简单融合（如 RRF），再做重排。
8. **文档生命周期**：文档版本、更新、下架、删除传播；RAGFlow 侧至少提供手动重建入口。

### P2
9. 文档级/段落级权限。
10. 查询改写、同义词/术语表、知识来源可信度与内容过期提醒。
11. 语义向量实体链接与图谱/向量融合。
