# 大文件处理 — 需求

> 本文定义大文件场景下"用户能上传什么、智能体如何访问、平台必须保证什么"。技术实现见 [设计](02-设计.md)。

## 1. 背景与问题

模型上下文窗口有限（当前约 128K tokens），而用户上传的文件经常远超这个体量：CSV 10–200MB、PDF 5–100MB、日志 100MB–1GB、代码压缩包 50–500MB。

把文件内容直接塞进上下文既不可行，也会让单次调用成本失控。平台需要让智能体"知道文件存在、知道结构、按需取片段"，而不是"读完整个文件"。

## 2. 目标

- 大文件可以上传并持久化，不进入模型上下文。
- 智能体在上下文中只看到文件摘要（类型、大小、行数、列结构、少量预览）。
- 智能体能通过工具按范围读取、搜索、查询、切片，按需获取内容。
- 任何一次工具调用都有输出上限，避免把大结果再次灌进上下文。
- 上传、解析、访问都受用户、会话、工作区与配额约束。

## 3. 范围

**纳入**：
- 单文件上传、大小校验、工作区配额。
- 异步分析文件元数据（行数、列、编码、页数、压缩包文件树等）。
- 智能体感知：系统提示中的轻量文件引用。
- 按需访问工具：元数据、按行/字节读取、正则搜索、结构化查询、切片。
- 沙箱内原生命令（head/tail/wc/awk/sed/jq）作为补充。
- 工具结果超过阈值时落盘，返回预览与读取入口。

**不纳入**：
- 把完整文件内容注入模型上下文。
- 在平台侧做通用 ETL、数据仓库或长期数据集管理。
- 跨用户共享上传文件。
- 对二进制文件做语义理解（只做元数据与安全访问）。

## 4. 功能需求

### 4.1 上传与配额

- 支持 multipart 上传，单文件上限可配置（当前 500MB）。
- 校验文件类型（magic bytes）与大小；伪造扩展名不得绕过。
- 按用户与工作区统计已用空间；超配额拒绝并返回明确原因。
- 文件写入对象存储，并注入对应会话的沙箱工作区。
- 上传成功后异步触发分析，通过流式事件通知前端。

### 4.2 异步分析

- 分析在沙箱内执行，不读取完整内容到后端进程。
- 按类型提取元数据：CSV 行数/列/类型/空值率/样本；JSON 结构；文本行数与编码；PDF 页数；压缩包文件树；日志时间范围。
- 分析结果缓存，重复查询不重复计算；失败有状态与原因。
- 分析超时或文件损坏时，降级为"仅大小/类型"的元数据，不阻塞会话。

### 4.3 智能体感知

- 元数据就绪后，以轻量引用注入系统提示：文件名、类型、大小、行数、列结构、前几行预览。
- 注入内容控制在几百 tokens 量级，不随文件体积增长。
- 未分析完成的文件标注状态，避免模型误判为空文件。

### 4.4 按需访问

智能体至少需要以下能力：

| 能力 | 用途 |
|---|---|
| 元数据查询 | 获取类型、行数、列、预览，不读正文 |
| 按范围读取 | 按行号或字节区间读取，自动截断 |
| 正则搜索 | 返回匹配行与上下文，限制匹配数 |
| 结构化查询 | 对 CSV/Parquet 等执行只读 SQL，限制返回行数 |
| 切片 | 按行/字节切出子文件，供后续处理 |
| 沙箱命令 | 受限使用 head/tail/wc/awk/sed/jq 等 |

### 4.5 工具安全

- 路径限制在工作区内，禁止路径穿越。
- 只读查询与写操作分离；写操作受工具权限与确认策略约束。
- 单次输出有硬上限；超限截断并标记，完整结果落盘。
- 查询超时、结果过大、语法错误都返回可解释错误，不返回半截数据冒充完整结果。

### 4.6 处理流水线

按文件类型提供默认处理路径：表格类走结构化查询，文本/日志走搜索与切片，PDF 走分页读取，压缩包先列目录再按需解压。流水线不改变工具的权限与配额约束。

## 5. 非功能需求

| 维度 | 要求 |
|---|---|
| 上下文成本 | 文件感知的固定开销在几百 tokens 内，不随文件大小增长 |
| 上传性能 | 500MB 文件上传不阻塞其他会话；失败可重试 |
| 分析性能 | 大文件分析有超时与降级，不拖垮沙箱 |
| 安全 | 路径穿越、压缩炸弹、超大输出、恶意 MIME 都要有防护 |
| 隔离 | 文件按用户与会话隔离，跨用户不可见 |
| 可观测 | 上传、分析、访问、截断、失败都可追踪 |

## 6. 验收标准

- [ ] 上传 500MB CSV 后，智能体上下文中只出现摘要，不出现全量内容。
- [ ] 智能体能通过元数据知道行数、列名与类型，并据此选择查询方式。
- [ ] 按行读取与正则搜索都有明确的返回上限，超限时提示已截断。
- [ ] 结构化查询只能只读，且结果行数受限。
- [ ] 路径穿越、跨工作区访问、超配额上传被拒绝。
- [ ] 分析失败或超时不影响会话继续，文件仍可按大小/类型访问。
- [ ] 工具结果超过阈值时落盘，模型拿到预览与后续读取入口。
