# D14 部署交付与运维

> **解决什么问题**：企业客户大量要求私有化与内网部署，“能跑起来”只是起点；还需要可重复安装、可升级、可回滚、可备份恢复、可排查故障。交付能力本身就是产品能力。
> **适用读者**：交付实施、SRE/运维、后端研发、售前与客户成功。
> **关联文档**：[D11 可观测性与运营](../D11-可观测性与运营/README.md) · [D12 成本与配额](../D12-成本与配额/README.md) · [能力全景 §5 D14](../../00-平台总览/README.md) · [用户与租户隔离](../D01-身份组织与权限/README.md)
> **状态基准**：2026-11 版本与部署配置。状态只用 `已具备 / 部分 / 缺失`。

---

## 1. 边界

**本文负责**：部署形态、交付物、依赖清单、配置与密钥、升级与回滚、备份恢复、日常运维与容量基线。

**本文不负责**：应用层可靠性机制（队列、熔断、多实例一致性，见 D13）；监控告警规则与 SLO（D11）；租户配额与计费（D12）；具体渠道/浏览器网关的功能配置（各自文档）。

**核心原则**：

1. **可重复安装**：同一份编排与配置在开发、测试、客户环境得到同样结果。
2. **升级前必须可回滚**：数据库迁移、对象存储、配置三部分都要有退路。
3. **密钥不进镜像、不进仓库**：由环境变量或密钥管理系统注入；备份必须演练，未演练的备份不算备份。

## 2. 能力清单

### 2.1 部署形态

| 形态 | 说明 |
|---|---|
| SaaS 多租户 | 单套平台服务多个租户，应用层按租户隔离 |
| 私有化单机 | 客户机房单机容器编排，基础服务与应用分离 |
| 内网/离线 | 无外网环境，镜像与依赖需离线导入 |
| 多实例 | 同一容器运行时上多个后端副本，需共享锁目录与 Redis |

### 2.2 交付物

- 容器镜像：后端、前端、沙箱，多架构（amd64/arm64）；编排文件覆盖应用、基础服务、可选浏览器网关叠加层与环境变量模板。
- 数据库迁移链随镜像发布。
- 安装/升级/回滚/备份恢复脚本、故障手册、版本兼容矩阵（应用 ↔ 数据库迁移版本 ↔ 沙箱镜像）。

### 2.3 依赖清单

| 依赖 | 用途 | 必需 | 说明 |
|---|---|---|---|
| PostgreSQL | 主数据、观测明细、预聚合 | 是 | 16 版本 |
| Redis | 定时任务抢占、任务注册表、事件唤醒 | 是 | 7 及以上；事件与注册表可降级 |
| 对象存储 | 工作区、技能包、导出 | 是 | MinIO，S3 兼容 |
| 容器运行时 | 沙箱容器执行 | 是 | 需挂载其控制接口 |
| 沙箱镜像 | 工具与代码执行 | 是 | 与后端镜像同源构建 |
| Langfuse | 链路追踪 | 否 | 独立编排，外部数据库/Redis/对象存储 + 分析库 |
| RAGFlow / MinerU | 知识库 / 扫描版 PDF | 否 | 后台配置或云服务令牌 |
| 浏览器网关 | 浏览器自动化 | 否 | 独立叠加层，需公网 TLS |

### 2.4 配置与密钥

- 配置来源：按数据库、Redis、认证、Agent、沙箱、存储、追踪、浏览器等分组的运行环境变量；LLM 供应商与模型由管理后台写入数据库，不在环境变量中。
- 必须管理的密钥：认证签名密钥（不少于 32 字符）、对象存储访问密钥、浏览器网关独立随机密钥（与认证密钥分离）、渠道应用密钥、模型 API Key、知识库平台密钥、扫描解析令牌、代码托管平台令牌。
- 多环境：开发/预发/生产使用独立配置、数据库与存储桶；服务地址、页面基地址与跨域来源按环境设置。

### 2.5 升级与回滚

- 升级内容：应用镜像、沙箱镜像、数据库迁移、配置变更。
- 顺序：备份 → 按镜像摘要拉取 → 启动触发迁移 → 健康检查 → 冒烟。
- 回滚：镜像退回上一摘要；数据库若已执行不可逆迁移，只能恢复备份；应用启动会自动迁移到最新版本，旧应用配新库不保证可用（需确认）。

### 2.6 备份恢复

- 备份对象：PostgreSQL（业务表 + 观测明细 + 迁移版本）、对象存储桶、运行配置、Langfuse 元数据（如启用）。
- RPO/RTO 按客户等级定义；季度至少一次全量恢复到隔离环境，校验登录、对话、文件、定时任务。

### 2.7 运维与容量

- 健康检查：存活/就绪、依赖连通性、迁移状态；日志标准输出采集、轮转、按请求追踪标识检索。
- 指标告警：主机、容器、数据库、Redis、对象存储、应用失败率（见 D11）；巡检磁盘/卷、沙箱残留、定时任务漏跑、备份、证书。
- 容量：最低/推荐配置、并发会话、沙箱并发、数据库连接数、存储增长。

## 3. 本项目现状

### 3.1 已具备

| 能力 | 实现 |
|---|---|
| 应用编排 | 应用编排覆盖沙箱镜像预拉取、后端、前端，含健康检查与依赖顺序 |
| 基础服务 | 独立编排提供 PostgreSQL 16、MinIO、Redis 7，使用独立项目与网络 |
| 网络隔离 | 应用与基础服务通过独立外部网络连接 |
| 沙箱部署 | 后端挂载容器运行时控制接口与共享锁卷；沙箱镜像有独立构建入口 |
| 前端/网关 | Nginx 静态站点 + 反向代理（SSE 不缓冲）；浏览器网关仅绑定本机回环地址 |
| Langfuse | 独立编排，复用外部数据库/Redis/对象存储，本地分析库 |
| 镜像与 CI | GitHub 容器镜像仓库与阿里云镜像仓库发布多架构“最新”与版本标签；后端 lint/类型/测试，前端类型/lint/构建/测试 |
| 数据库迁移 | 迁移链随镜像发布；启动自动升级，多实例通过数据库咨询锁串行化 |
| 迁移保护 | 拒绝未标记版本的旧库；超时 600 秒停止启动；历史补丁迁移 |
| 配置模板 | 覆盖数据库、Redis、认证、Agent、沙箱、存储、追踪、知识库、浏览器 |
| 健康检查 | 健康检查返回服务状态与沙箱活跃数；编排按固定间隔检查 |
| 数据卷与进程 | 保留数据卷命名；进程看护防止孤儿进程，启动/关闭按依赖顺序清理 |

### 3.2 部分

- **只支持单机容器编排**：没有 Helm/K8s 清单；镜像支持 arm64，但未验证 ARM 生产部署。
- **多实例能力受限**：后端依赖宿主机容器运行时控制接口与共享锁目录，多副本必须同宿主；采集队列、定时调度、SSE 连接仍以进程内状态为主。
- **迁移是单向的**：启动自动升级到最新版本；不可逆迁移不提供自动降级，回滚依赖“经过验证的备份恢复方案”，但仓库没有备份工具。
- **Redis 无持久化**：未挂载数据卷；定时任务抢占记录（保留 24 小时）与任务注册表（30 分钟过期）重启后丢失，可能导致漏跑或重复执行窗口。
- **健康检查只有存活**：不检查数据库、Redis、对象存储，也没有就绪检查；依赖故障时容器仍可能被判健康。
- **密钥明文**：模型与渠道密钥的存储字段虽以“加密”命名，写入处仍是明文；知识库平台密钥以明文存入系统配置；无密钥管理服务。
- **日志未接入**：日志默认控制台输出，未配置结构化格式、追踪标识、采集器或轮转；日志级别只影响 Web 服务器与 SQL 回显。
- **CI 只到构建**：没有部署流水线、镜像扫描、软件物料清单、环境晋级；**离线交付未落地**（无镜像导出包与内网脚本）；**容量基线未定义**。

### 3.3 缺失

- Helm Chart、K8s 清单、Operator；应用版本与数据库迁移版本的兼容性矩阵、变更日志。
- 备份/恢复脚本、定时备份、恢复演练记录；升级前预检与自动回滚。
- 许可证管理与授权校验；多租户独立部署/独立数据库方案。
- 故障手册、巡检脚本、值班轮换与升级通知模板；离线镜像仓库与内网代理方案。

## 4. 关键设计

### 4.1 部署拓扑

- 浏览器经客户提供的反向代理/负载均衡与 TLS 接入。
- 前端静态站点对外，并反向代理后端接口。
- 后端连接 PostgreSQL、Redis、对象存储与宿主容器运行时；沙箱容器由容器运行时拉起。
- 可选部署浏览器网关与 Langfuse 独立项目。

- 应用与基础服务是两个独立编排项目；停止应用编排不会停基础服务。
- 生产必须由客户反向代理终止 TLS 并限制来源；启用浏览器网关时只暴露扩展接入所需路径。

### 4.2 依赖与暴露范围

| 服务 | 暴露范围 | 说明 |
|---|---|---|
| 前端 / 后端 | 仅前端对外 | 后端只经前端反向代理访问，不直接映射宿主 |
| PostgreSQL | 仅内网 | 生产建议不映射宿主 |
| MinIO | 内网，浏览器与后端均可达 | 对象存储地址需两端都能访问 |
| Redis | 仅内网 | 默认无密码，生产必须加访问控制/密码 |
| 浏览器网关 | 本机回环 | 需额外反向代理才能对外暴露 |

### 4.3 升级流程

1. **备份**：数据库全量 + 对象存储桶清单/关键对象 + 当前运行配置与镜像摘要。
2. **预检**：确认目标与当前迁移版本路径，检查磁盘、连接数、沙箱残留。
3. **发布**：按摘要拉取后端/前端/沙箱镜像并启动应用编排。
4. **迁移**：启动时自动加数据库咨询锁并升级到最新版本；失败则启动中止，旧容器仍可用。
5. **验证与观察**：健康检查、登录、对话、工具、文件、定时任务、观测写入；观察 15–30 分钟错误率与延迟，异常则回滚。

### 4.4 回滚与兼容性

- 镜像回滚：切换到上一摘要重新启动；配置回滚：保留上一版运行配置。
- 数据库回滚：**仅能通过备份恢复**；迁移链不保证自动降级，历史修复迁移明确不提供自动回滚。
- 因此升级前备份是硬门槛；沙箱镜像应与应用镜像同版本发布，仅升级应用可能造成工具行为不一致。

### 4.5 备份、RPO/RTO

| 对象 | 建议方式 | 建议频率 | 当前状态 |
|---|---|---|---|
| PostgreSQL | 每日全量 + 预写日志归档 | 全量日备、日志持续 | 缺失 |
| 对象存储 | 镜像复制到备份桶/异地 | 每日 | 缺失 |
| 运行配置 | 密钥管理系统版本化 | 每次变更 | 部分（人工保存） |
| Langfuse | 随其数据库/分析库基础备份 | 每日 | 缺失 |

Redis 可不备份（状态可重建），但需接受定时任务抢占记录与任务注册表丢失后的漏跑窗口。

**建议目标（需与客户确认）**：核心业务库 RPO ≤ 15 分钟，对象存储 RPO ≤ 24 小时；单机故障 RTO ≤ 2 小时，数据恢复 RTO ≤ 4 小时；每季度恢复演练并记录实际 RTO。

### 4.6 密钥管理

- 认证签名密钥未配置或长度不足时应用拒绝启动；轮换会使全部旧令牌失效。
- 浏览器网关密钥必须独立于认证签名密钥，至少 32 字符。
- 生产建议由密钥管理服务/保险库/云密钥管理注入，容器只读环境变量；镜像层与进程信息不得出现密钥；渠道/模型密钥应加密存储并记录轮换审计。

### 4.7 多实例与横向扩展约束

- 后端与宿主机容器运行时强绑定：多副本必须共享同一运行时与同一锁目录卷。
- 定时任务通过 Redis 抢占防重复，迁移通过数据库咨询锁串行化；观测队列与部分任务状态为进程内状态，多实例下报表与任务可见性可能不完整（需确认）。
- 未验证前不建议跨主机水平扩展；优先纵向扩容与拆分后台任务。

### 4.8 容量基线

| 项 | 默认值 | 说明 |
|---|---|---|
| 沙箱并发 | 配置项默认 10 | 该配置当前未接入执行点，实际并发由活跃用户与宿主机能力决定（见 D13） |
| 沙箱 CPU/内存 | 1.0 核 / 512 MB | 单容器上限 |
| 命令超时/工作区 | 60 秒 / 500 MB | 长任务需调大或拆分 |
| 沙箱空闲回收 | 3600 秒 | 执行中不回收 |
| 后端进程 | 1（无多工作进程） | 单进程运行 |
| 主机规格 | 需确认 | 仓库无最低/推荐配置说明 |

## 5. 实施建议

### P0（私有化交付的最低门槛）

1. 备份/恢复脚本与定时任务：数据库全量 + 预写日志、对象存储镜像、配置备份；升级前强制校验最近备份。
2. 发布可回滚：镜像固定摘要、保留上一版本、升级失败自动/手动回退步骤文档化。
3. 健康检查分层：存活与就绪分离，就绪检查数据库、Redis、对象存储与迁移版本；Redis 至少开启持久化，并把抢占记录丢失的影响写进运维手册。
4. 密钥加密：模型/渠道/知识库密钥落库前加密，密钥来源统一；离线交付包（镜像导出、依赖清单、内网脚本）。

### P1（可运营）

5. Helm Chart / K8s 清单（含持久卷、探针、资源限额、中断预算）；版本兼容矩阵与变更日志、升级预检脚本。
6. 日志采集、指标接入与告警（对接 D11）。
7. 故障手册与巡检脚本：磁盘、沙箱残留、定时任务漏跑、证书、备份。
8. 容量压测与最低/推荐配置表。
9. 多环境晋级流水线（预发 → 生产）与镜像扫描/软件物料清单。

### P2（规模化与商业交付）

10. 多租户独立数据库/独立部署方案；许可证管理与授权校验。
11. 灰度升级与双版本并行；跨主机多实例与共享存储方案。
12. 客户侧自服务安装器与一键诊断包。
