## 本地浏览器远程控制 — 需求文档

> 状态：首期基础闭环已实现，完整目标范围保留如下。日期：2026-10-30。
> 选型：BrowserSkill 官方扩展 + 平台 Browser Gateway。
> 配套：技术方案见本文第二部分。实现范围、配置与实测边界见 [部署与验收](01-运行手册.md)。

### 2026-10-31 授权需求更新

新增用户主动开启的持续授权：一次授权后持续有效，直到撤销；适用于当前用户和设备所属租户，允许任意公开 HTTP/HTTPS 网站，打开、点击、填写、选择、按键、滚动不再逐次确认。登录、验证码、支付由用户接管，智能体使用 `local_browser_request_help` 请求协助。每轮仍创建独立执行授权并检查对象租户、成员资格、工具开关和运行租约；持续授权不能由模型自行开启，也不开放委派、渠道或定时任务执行。

默认仍保留原有的逐轮网站授权模式。下文涉及「逐次确认」「网站白名单」「30 分钟」的要求适用于该模式；持续授权的用户选择优先。设备连接凭证继续轮换续期，不能通过永久不变的共享密钥实现持续授权。多台已授权设备同时在线时由用户选择，不能由模型任意挑选设备。

### 1. 目标与接入方式

用户在本地 Chrome / Edge 安装 BrowserSkill 扩展，通过一次性配对链接连接平台。云端智能体通过平台工具操作用户授权的浏览器，复用该浏览器 Profile 的网站登录态。本地无需运行 Python、Node、CLI，也不需要开放入站端口。

浏览器扩展主动通过 WSS 连接云端。平台管理设备归属、任务授权、操作记录与取消；扩展负责标签页控制、页面读取、原生操作和人工接管。

现有 `ui_*` 继续操作平台自身页面。新增 `local_browser_*` 操作本地浏览器中的外部网站，使用独立设备和任务授权，不混用页面引用。

### 1.1 具体业务场景

- 用户说「打开百度」：在用户自己电脑的浏览器任务窗口打开百度，用户能看到真实页面。
- 用户说「打开百度，搜索浏览器自动化」：打开页面、读取搜索框、逐次确认后填写和搜索，返回可读取的结果；验证码由用户接管。
- 用户说「打开京东，搜索耳机」：在用户本地浏览器打开京东并执行搜索；复用该 Profile 的登录态，涉及登录和验证码由用户操作。
- 不是只抓取网页文本或打开云端无头浏览器，也不局限于控制平台自己的页面。设备和页面始终绑定发起用户及任务所属租户。

### 2. 用户流程

1. 用户进入当前租户的「我的浏览器」，点击「连接浏览器」，看到租户、账号和安装指引。
2. 平台生成有效期 5 分钟的一次性链接；用户在扩展的 Remote connection 中粘贴链接。
3. 平台显示浏览器名称、版本、在线状态。配对与连通验证分别展示；没有成功握手不能显示「已连接」。
4. 用户在聊天输入区选择自己的在线浏览器，开启「本次任务使用浏览器」，检查授权范围后发送请求。设备选择和授权绑定这一轮任务，不默认为所有后续对话开放。
5. 智能体建立独立任务窗口，读取页面，逐步操作；聊天显示设备、执行租户、当前网站、操作状态和停止按钮。
6. 使用用户已有标签页时，由用户在选择器中选中并授权借用。平台授权之外，继续遵守扩展自身的借用确认设置。
7. 登录、验证码、付款确认等需要人工完成时，用户在本地页面接管；密码和验证码不经过聊天输入。
8. 任务结束或用户停止后释放控制、归还借用标签页。清理失败必须显示「待清理」，不能假报成功。

### 3. 首期范围

| 能力 | 首期设计 |
|---|---|
| 设备连接 | Chrome / Edge 官方扩展、WSS、配对、续期、断线检测、撤销 |
| Web 聊天 / 宠物聊天 | 走普通 Web ChatRun，用户为本次任务选择设备并授权 |
| 页面操作 | 新建任务页、导航、观察、截图、点击、填写、选择、按键、滚动、等待、归还和结束 |
| 现有标签页 | 用户选择后借用；模型不能遍历用户所有标签页 |
| 人工接管 | 扩展原生暂停/求助；重新观察后才能继续 |
| 任务预览 | 按需低频预览；扩展不支持时显示状态并降级，不阻止基本操作 |
| 定时任务、渠道、开放 API | 首期不授予本地浏览器权限；后续单独设计无人值守授权 |
| 多智能体委派、协作房间 | 首期不传递浏览器授权；避免并发控制及私有页面进入共享上下文 |
| 通用脚本 / CDP / 网络调试 | 首期不开放给模型 |
| 远程上传和下载 | 当前上游远程模式不支持，不伪装为已支持；本地下载不能被当作云端产物 |

以上范围是本方案的实施切分，不代表上游不具备其他能力。

### 4. 隔离与授权要求

- 每个设备授权固定属于一个 `tenant_id + user_id`，不提供租户共享设备。租户管理员可以禁用能力/撤销授权，不能代替设备主人控制浏览器或查看页面内容。
- 相同用户在 A/B 租户拥有独立设备授权、任务、事件和产物。切换界面租户不改变正在执行的任务归属。
- 每轮任务显式绑定执行租户、用户、智能体、ChatRun、设备及有效期。模型只能使用服务器发出的短期句柄，不能指定用户、租户、设备凭证或原生会话 ID。
- 每次操作都重新检查用户、租户、成员资格、智能体可见性、授权、设备及任务状态；丧失任何条件后拒绝后续操作。
- 一个设备同时只允许一个活动浏览器任务。不同用户的设备可并行执行；占用冲突直接提示，不偷偷切换设备或标签页。
- 配对表示允许平台连接设备；「本次任务使用浏览器」才表示允许某轮 Agent 使用它。两者不能合并为永久执行权限。
- 读页面、截图、预览、SSE、查询结果、停止、续期和撤销都必须进行对象归属校验，不能只保护点击接口。

**隔离边界：** BrowserSkill 的任务窗口共享 Profile 的网站账号、Cookie 和存储。平台可以隔离控制权和云端数据，不能凭空隔离同一 Profile 内不同租户的网站账号。需要独立账号边界时，用户必须为各租户使用独立 Chrome/Edge Profile；普通窗口、标签分组和无痕窗口均不能被描述成租户安全容器。

### 5. 操作授权和人工控制

- 用户授权卡明确显示：任务目的、浏览器、租户、计划访问的网站、是否允许交互及到期时间。
- 默认确认模式：观察/截图在本次任务授权内执行；导航、新建/借用标签页和交互动作通过平台操作确认后执行。任意网站的点击、填写都可能产生业务副作用，不能只通过按钮文字判断是否危险。
- 可由用户主动选择「本次任务允许在所选网站连续交互」，减少重复确认；界面明确这可能包含网站提交，不宣传为“只填表绝不提交”。平台/租户可以禁用这一模式。
- 检测到支付、删除、发送等敏感行为时仍暂停确认；此检测是补充措施，不是识别任意网站副作用的保证。
- 新网站或超出原任务范围时重新授权。域名范围是平台命令策略，不宣称能够隔离网页的全部子资源、重定向或服务端副作用。
- 本地人工停止和平台停止均优先于 Agent。已经发送给浏览器的操作无法保证撤回，结果未知时要求核对，不自动重试提交。

### 6. 验收场景

| 场景 | 必须达到的结果 |
|---|---|
| 云端公网部署，本地在 NAT 后 | 仅通过本地出站 HTTPS/WSS 完成配对、读页、交互和停止 |
| 同租户两个用户 | 不能控制、预览、读取或批准对方的设备/任务；伪造 ID 也失败 |
| 同用户属于 A/B 两租户 | A 任务不能使用 B 设备、页面引用、确认或产物 |
| 运行中切换到 B，甚至 B 停用 | A 任务按 A 的真实成员资格继续；不修改 `users.tenant_id` |
| A 成员被移除 / A 停用 / 智能体私有不可见 | 拒绝后续操作并回收授权；不回退界面租户 |
| 本地浏览器断开 / 电脑休眠 / 网关重启 | 原会话失效；重连不重放操作，不自动恢复写入 |
| 点击已生效但响应丢失 | 显示结果未知，不自动再次点击 |
| 人工改变页面 / 关闭或移走受控标签 | 旧观察失效，不把旧动作补上新上下文后继续执行 |
| 多个 API worker / 重复操作确认 | 只有一次有效批准与派发，停止可跨 worker 生效 |
| 设备撤销、凭证重放和更新竞态 | 旧连接停止、过期凭证无效、精确续期重试幂等 |
| 页面包含恶意指令 | 不能扩大设备、工具、租户或任务授权 |
| 截图、日志、记忆和共享 | 不泄露配对凭证；私有页面不进入共享工作区、全局记忆或通用 Hook |

真实浏览器、真实公网链路、PostgreSQL 并发/RLS 回归均属于上线前门槛。已完成和待完成的验证见 [部署与验收](01-运行手册.md)，未实现目标不作为首期交付声明。

## 本地浏览器远程控制 — 技术方案

> 重建说明：原技术方案文件未纳入 git，删除后无法恢复。本文依据 `browser/` 代码、数据库模型与 D04 总览重建，覆盖首期实现，不包含已丢失的设计论证细节。

### 1. 架构

```
用户本地 Chrome ── BrowserSkill 扩展 ──WSS──> Browser Gateway (8101)
                                                   │
                                            backend/browser/service.py
                                                   │
                                       DB: pairings / devices / grants /
                                           sessions / commands / observations
                                                   │
                                            AgentLoop / local_browser_* 工具
```

- 扩展出站连接，平台不主动连用户机器。
- Gateway 独立端口（默认 8101），可单独部署与限制来源。
- 浏览器动作由 `browser/service.py` 统一编排，工具层只暴露能力级接口。

### 2. 身份与配对

| 对象 | 作用 | 关键约束 |
|---|---|---|
| `browser_pairings` | 一次性配对码 | 短期有效，绑定用户、租户与请求 ID |
| `browser_devices` | 已配对设备 | 凭证只存摘要；可轮换、吊销；记录最后在线 |
| `browser_run_grants` | 单次运行授权 | 绑定设备、智能体、会话、运行；记录精确 origin、过期与撤销 |
| `browser_sessions` | 浏览器会话 | 每设备同时只允许一个 occupied 会话；`connection_epoch` 防止旧连接复活 |
| `browser_commands` | 命令队列 | `request_id` 幂等；`payload_digest` 绑定审批内容 |
| `browser_observations` | 观察结果 | 截图/DOM 等结果按命令认领，防止串会话 |

**流程**：
1. 用户在管理端创建设备配对，得到一次性配对链接/码。
2. 扩展用配对码换取设备凭证；凭证只在扩展侧保存。
3. Agent 需要操作浏览器时，前端要求用户选择设备与授权范围（origin、单轮/持续）。
4. 运行开始时创建 grant，绑定 `chat_run_id` 与 `agent_id`；`agent_id` 不可在执行中更换。
5. 会话打开后，命令按 `request_id` 入队；扩展执行并回传观察结果。
6. 运行结束、用户停止、断线超时或权限撤销时清理会话与 grant。

### 3. 授权模型

- **逐轮授权**：grant 绑定单个 `chat_run_id`，运行结束即失效。
- **持续授权**：用户显式开启后，设备级持久授权生效；仍受 origin 与设备状态约束。
- **origin 白名单**：grant 保存规范化后的精确 origin，导航到未授权 origin 一律拒绝。
- **人工接管**：登录、验证码、支付三类操作禁止模型执行，只能请求用户接管（`local_browser_request_help`）。
- **撤销**：吊销设备、撤销 grant、停止会话三条路径都要求终止在途命令并释放占用。

### 4. 工具面

工具名统一为 `local_browser_*`，全部注册为 `execution_location="local_browser"`，超时 420 秒。

| 能力 | 说明 |
|---|---|
| 打开/导航 | 只允许 http/https；URL 长度上限 4096 |
| 观察 | 同步或等待；返回截图与可操作元素 |
| 点击/输入/滚动 | 基于观察结果定位，不接受任意 JS |
| 截图 | 受配额限制，避免刷屏与成本失控 |
| 请求帮助 | 交给用户完成登录/验证码/支付，然后重新观察 |
| 停止/清理 | 用户主动停止；断线后确认清理 |

**不暴露**：原始 RPC、JavaScript 求值、设备 ID、直接 HTTP 凭据。

### 5. 隔离与安全

- 所有对象带 `user_id` 与 `tenant_id` 归属，查询必须同时校验。
- 执行入口使用对象所属租户，不读取界面当前租户。
- 私有聊天（`browser_private`）不触发 Hook、不写入共享上下文；`private_chat_scope` 单独校验。
- 扩展来源只接受 `chrome-extension://`；WSS 必须 TLS；loopback 仅限开发配置。
- 设备凭证、配对码、命令参数中的敏感字段不进入日志与模型上下文。
- 命令审批绑定 `payload_digest`，参数变化导致审批失效。

### 6. 失败模式

| 场景 | 行为 |
|---|---|
| 扩展断线 | 会话标记断线；等待心跳超时后释放占用；不自动重试命令 |
| 命令结果未知 | 不盲目重试，要求重新观察后决策 |
| 用户撤销授权 | 终止会话、拒绝在途命令、释放设备 |
| 导航到未授权 origin | 拒绝并返回明确错误 |
| 同一设备并发会话 | 数据库唯一约束阻止第二个 occupied 会话 |
| 旧连接回连 | `connection_epoch` 不匹配则拒绝 |

### 7. 配置

| 配置 | 说明 |
|---|---|
| `BROWSER_ENABLED` | 总开关，默认关闭 |
| `BROWSER_SECRET_KEY` | 凭证与配对码签名密钥 |
| `BROWSER_PUBLIC_WSS_URL` | 扩展连接地址 |
| `BROWSER_ALLOW_LOOPBACK_WS` | 仅开发使用 |
| `BROWSER_PAIRING_TTL` | 配对码有效期 |
| `BROWSER_GRANT_TTL` | 单次授权有效期 |
| `BROWSER_CREDENTIAL_TTL` | 设备凭证有效期 |
| `BROWSER_RPC_TIMEOUT` | 单命令超时 |
| `BROWSER_APPROVAL_TIMEOUT` | 审批超时 |
| `BROWSER_HEARTBEAT_TIMEOUT` | 心跳超时 |
| `BROWSER_MAX_CONNECTIONS` | 最大连接数 |
| `BROWSER_MAX_FRAME_BYTES` | 单帧上限 |
| `BROWSER_PORT` | Gateway 端口 |
