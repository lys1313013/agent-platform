# 运行时实现说明 — 需求

> 让智能体执行脱离连接生命周期，做到可观察、可停止、可安全恢复，并统一执行契约与运行环境查询。技术实现见 [设计](02-设计.md)。

## 1. 背景与问题

过去 Web 对话与请求生命周期绑定：刷新、切换会话、离开页面或关闭宠物面板会中断执行，断线后无法继续观察进度；停止依赖前端断开或固定延迟猜测，停止与下一条消息之间存在竞态；进程崩溃后，运行中的任务状态不明确。

同时，普通 HTTP、Web 流式、WebSocket、已发布 API、渠道、定时任务与房间各自组装执行流程，执行租户、智能体绑定、模型选择、工具授权和确认语义容易分叉。用户与运维也缺少一个只读入口来回答“智能体运行在哪台设备、当前是什么系统、沙箱是否可用”。

## 2. 目标

- 后台任务与订阅解耦：断开订阅不影响执行，重新进入可恢复观察。
- 执行状态持久、可重连、可停止，并只在安全条件下续跑。
- 统一一次执行的归属、模型、工具授权、确认与接口契约。
- 提供只读、受权限约束的运行环境查询，并明确信息边界。

## 3. 范围（纳入 / 不纳入）

纳入：

- Web 普通聊天、智能体聊天、门户与宠物对话的后台任务化。
- 任务状态与事件持久化、心跳、断线重连、事件回放、显式停止与安全续跑。
- 同一会话的并发约束、删除约束、正常停机与强制终止的中断语义。
- 普通 HTTP、Web 流式、WebSocket 与已发布 API 的统一执行准备；渠道、定时任务与房间复用公共能力。
- 执行租户、绑定智能体、模型冻结、工具授权、确认与流式接口契约。
- 运行环境查询，以及沙箱不可用时的降级启动与后台恢复。

不纳入：

- Python 调用栈级别的恢复；续跑不是进程内断点续传。
- 外部系统副作用的通用 exactly-once 保证。
- 事件回放时重新执行浏览器点击、输入或提交。
- 工具实现、MCP 连接与沙箱隔离本身。
- 确认与浏览器动作处理的外置，以及跨副本无粘性部署。
- 任务事件日志的定时清理、容量与 SLO 规划。
- 模型目录、路由与配额管理。

## 4. 功能需求

### 4.1 后台任务与生命周期

- 刷新、切换会话、离开页面或关闭宠物面板只断开订阅，不得终止后端执行。
- 再次进入会话时自动查询最新任务，加载历史并从事件起点重建该轮进度；必须按任务标识、事件序号和消息标识去重。
- 聊天地址必须能定位具体会话，刷新和前进后退可回到原会话。
- 停止必须显式取消父任务及已登记的委派子任务，保存已有进度；队列中的下一条消息等待停止完成后再发送。
- 同一会话同一时刻只允许一个运行中的 Web 任务；运行中的会话必须先停止才能删除。
- 正常停机将运行中任务保存为已中断；强制终止时心跳超时后，应在状态查询或订阅时标记为已中断。
- 不得因另一副本启动而把健康任务误标为中断。
- 停止、失败或中断的任务在满足安全条件时提供“继续任务”；存在结果未知或失败的工具调用时禁止一键续跑，并提示先核对外部结果。

### 4.2 执行与持久化语义

- 每个任务必须有明确归属与唯一终态；事件按单调递增序号持久化，支持从指定序号回放。
- 工具调用事件必须在进入执行前持久化，工具结果必须在推进下一步前持久化；文本增量可批量提交。
- 完成事件必须在终态提交后通知订阅者，不得让前端抢跑。
- 强制终止可能丢失最后一个未提交的文本批次；完成事件已持久化时，进程崩溃后应恢复为已完成。
- 删除会话必须同时删除其任务与事件。
- 所有任务与事件查询必须限定当前用户；状态查询、事件重连与停止请求必须可跨副本访问。

### 4.3 安全续跑

- 续跑必须关联原任务并建立新一轮，使用已持久化的对话与工具结果继续，不得重新提交原始问题。
- 同名同参数的已完成工具调用必须直接复用旧结果，连续多次续跑同样复用，不得再次执行外部操作。
- 不存在持久成功结果的工具调用必须阻止一键续跑；失败响应不得自动视为安全重试。
- 工具结果未知时，历史必须明确标记未知，并补充符合模型协议的工具响应，避免后续请求失败。
- 事件回放不得重新触发浏览器动作；保护只针对已有调用记录和精确匹配参数，不承诺通用 exactly-once。

### 4.4 执行契约

- 已有对象的执行与查询必须先校验会话归属、绑定智能体可见性、执行租户与成员状态，不得先校验界面当前租户。
- 请求中的智能体必须与会话一致；显式改绑仅允许同租户且无运行中任务。
- 执行租户与执行智能体由服务端写入，执行期内不可变；一次执行内固定模型，历史图片格式与实际模型调用一致，已发布配置使用快照。
- 普通 HTTP、Web 流式、WebSocket 与已发布 API 必须共用执行准备；渠道、定时任务与房间保留各自输入和持久化流程，但共用模型选择、工具过滤与运行时创建。
- 未绑定智能体不得获得 MCP 工具；调用时必须再次核验服务租户、启用状态与用户成员资格。
- 工具信任级别取自执行用户配置，缺省使用全局默认；委派继承同一用户策略。
- 确认必须在运行时内等待并通知前端；归属由服务端固定为执行租户，恢复和提交时复查成员资格。只有批准才按原参数执行；拒绝、修改、超时、取消或缺少交互通道均不得执行。
- 状态、回放、续跑与停止必须复查来源对象；订阅期间持续复查权限，失效时发送权限撤销事件并结束。
- 删除会话只能由统一入口提供且成功无响应体；更新语义与流式媒体类型、事件结构必须稳定并写入接口描述。

### 4.5 运行环境查询

- 必须提供只读内置工具回答设备、系统、后端进程位置、时区、执行上下文与沙箱状态；默认执行沙箱检查、不返回资源信息，可选返回资源信息。
- 必须遵循既有工具白名单与信任级别规则，不绕过智能体可用工具限制，也不构成新的执行入口。
- 设备标识必须明确是主机名哈希而非硬件标识；设备名称必须说明来源，获取失败时回退主机名；容器内查询只反映容器视角。
- 信息来自智能体编排后端，不得被误认为打开网页的设备或远程模型服务；Docker 可能在另一台设备，不能据此推断沙箱与后端共用宿主机。
- 资源信息必须标注为后端视角，可能反映宿主机容量而非容器配额；无法读取项明确返回未知。
- 执行上下文只读取已绑定的执行租户，不得查询、缓存或回写界面当前租户；跨用户上下文必须拒绝。
- 返回内容必须白名单化，不枚举环境变量、密钥、网络接口、硬件序列号或完整路径；时区只承诺缩写与 UTC 偏移。
- 沙箱检查必须使用独立连接与短超时，只检查当前用户、当前部署对应的固定容器，不得枚举其他容器、创建或启动容器、执行命令、接管容器、同步文件或刷新空闲时间。
- Docker 可连接不等于代码可执行，必须标注执行能力未经验证；容器不存在时返回未创建状态；Docker 不可用时仍返回设备信息与脱敏原因。
- 启动时 Docker 不可用不得终止后端，应降级启动并后台按周期重试；需要沙箱的操作重试后仍失败时明确报错，其他启动错误仍按原规则处理。

## 5. 非功能需求

- 一致性：每个任务只有一个所有者与唯一终态；事件序号单调，完成事件不早于终态提交。
- 可恢复性：强制终止后应在心跳超时（约 30 秒）内经状态查询或订阅识别为中断；已完成任务不得回退为运行中。
- 可用性：常规停机与心跳异常不得造成状态错乱；数据库不可用或所有权失效时，执行者应取消本地执行。
- 安全：状态、回放、续跑与停止查询限定用户；执行归属由服务端固定；权限撤销后不得恢复读取权限。
- 兼容性：保留既有流式形状与已发布 API 的命名事件、文本增量字段；新增任务标识、事件序号与回放标记不得破坏既有客户端。
- 多实例：任务状态、事件重连与停止可跨副本；确认与浏览器动作仍为进程内状态，部署需保持会话粘性。
- 性能：沙箱检查单次超时约 1 秒且不阻塞设备信息返回；文本事件批量提交以控制写放大。

## 6. 验收标准

- [ ] 聊天中刷新、切换会话或关闭宠物面板后后端继续执行；重新进入能看到完整进度且不重复追加，刷新或前进后退能回到原会话。
- [ ] 停止后父任务与已登记子任务均被取消并保存进度；立即发送的下一条等待停止完成。
- [ ] 同一会话重复发起执行被拒绝；运行中的会话无法删除。
- [ ] 正常停机显示已中断；强制终止经心跳超时被标记中断；另一副本启动不会误标健康任务。
- [ ] 完成事件在终态提交后到达；终态落库后进程崩溃，任务仍恢复为已完成。
- [ ] 续跑复用同名同参数的已完成工具结果，不重复产生外部副作用；多次续跑仍复用。
- [ ] 存在结果未知或失败工具调用时禁止一键续跑并提示核对；未知结果在历史中有明确标记和协议响应。
- [ ] 事件回放只重建进度，不重新执行历史浏览器动作。
- [ ] 跨智能体请求、跨租户改绑、无权限访问均被拒绝；执行租户与智能体由服务端固定且执行期内不可变，同一次执行内历史图片格式与模型调用一致，已发布配置使用快照。
- [ ] 未绑定智能体拿不到 MCP 工具；调用时租户、启用状态或成员资格失效会被拒绝。
- [ ] 仅批准后按原参数执行；拒绝、修改、超时、取消或缺少通道均不执行。
- [ ] 订阅期间权限被撤销时收到权限撤销事件并结束。
- [ ] 运行环境查询返回设备、系统、后端进程、时区与执行上下文；可选资源与沙箱信息按参数返回。
- [ ] 沙箱检查只查看当前用户当前部署的固定容器，不创建、启动、执行或枚举其他容器。
- [ ] Docker 不可用时仍返回设备信息与脱敏原因，标注执行能力未经验证且启动不失败；返回结果不包含环境变量、密钥、网络接口、硬件序列号或完整路径。
